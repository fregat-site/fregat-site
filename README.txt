ФРЕГАТ — версия сайта с фотокаруселью

Эта папка собрана на основе текущей опубликованной версии сайта Фрегат.
Добавлено:
- новая секция «Жизнь Фрегата»;
- все 15 загруженных фотографий детей/занятий;
- горизонтальная карусель с автопрокруткой;
- стрелки назад/вперёд;
- перетаскивание мышью и свайп на телефоне;
- адаптация карусели под мобильные устройства;
- сохранены 9 карточек специалистов;
- сохранены актуальные блоки стоимости и контактов, включая VK, Telegram и MAX.

Для обновления GitHub Pages:
1. Открой репозиторий fregat-site/fregat-site.
2. Замени index.html, style.css и script.js файлами из этой папки.
3. Загрузите папку assets целиком с новыми фотографиями life-01.webp ... life-15.webp и остальными используемыми изображениями.
4. Commit changes.

Важно: не удаляй существующие файлы в assets, если они используются другими версиями сайта.
